Student
Management System

A database-driven application for organizing student information. Built with Express.js and Prisma ORM, connected to MySQL, and designed to demonstrate complete CRUD operations.

Open application ↗

ABOUT THE PROJECT

Project overview

StudentHub provides a central place to create, view, edit, search, and delete student records. Prisma Client handles database operations while MySQL stores records persistently. This project demonstrates database connectivity and ORM-based CRUD.

CORE CAPABILITIES

What it can do

Create records

Add student number, name, email, course, and year level.

Read records

Browse and search the student directory.

Update records

Edit existing student information.

Delete records

Remove records with a confirmation step.
